---
ref: SQ-114
title: A default arrow and a same-line callback no longer hide a dropped named function from the CRAP gate
bump: patch
plugins:
  - quartermaster
---

The CRAP gate treats an `(anonymous)` lizard row as standing in for a definition only when widening that
row lands on the definition's own parameter list, which is what lizard's misnamed row for an arrow-typed
parameter (`work: () => T`) does. A default arrow (`work = () => {}`) that lizard names `work`, or a
callback on the same line, no longer hides a named function lizard dropped.
