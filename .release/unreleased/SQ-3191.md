title: "A read-only ticket can close with done over the artifact its category's artifactRoots authorize (GH-332)"
bump: patch
plugins:
  - sidequest
---

A read-only `codebase-exploration` ticket dispatched into its own worktree couldn't close after writing the one file its category allows under `.claude/.codebase-info`. `done` refused with `done_scope_violation` because the closeout check never read the category's `artifactRoots`, so every declared-scope change counted against it. Now `done` skips paths under those roots for a read-only dispatch. Any other declared-scope change still refuses with the same reason, and the message and the new `artifactRoots` field name the roots that were allowed. The shared-tree artifact handoff that update-codebase-map uses already closed cleanly and is now pinned by a test.
