Sidequest's shipped Codex fallbacks for `experiment`, `coding.hard` and `spike-investigation` now name `codex-gpt-6-1-sol` (seed revision 9). On the next store load, every stored routing profile row and board category still on `codex-gpt-5-6-sol` or `codex-gpt-6-sol` (and their `-fast` forms) moves to GPT-6.1 Sol, and so does `codex-gpt-6-astra` outside a category whose id contains `frontier`. Rows pointing at anything else are left as the user set them. GPT-6.1 Sol is the default Codex model; GPT-6 Astra is reserved for frontier or high-stakes tickets.

Model Gateway has a `gpt-6.1-sol` window policy row, measured on 2026-09-30 at 920,012 input tokens accepted and 935,012 refused, and lists it in the fallback Codex catalog used when the proxy has no `/v1/models`.
