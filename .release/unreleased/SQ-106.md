Board-only rework note for PR #359 (GH-160). The orchestrator strips this fragment; the GH-160 fragment carries the release text.

A candidate could no longer avoid the negative-control gate by merging its own work from a side branch, by merging itself onto the integration branch tip, or by giving submit a range base at or near its own tip. A commit counts as foreign only when a ref of the ticket's integration target reaches it; every other commit is the candidate's own. A merge answers only for lines no parent had, and a test that only a merge resolution changed is now demanded.
