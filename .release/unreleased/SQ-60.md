ref: SQ-60
title: MCP add accepts dependsOn and either storyId form; glob file scopes no longer false-positive
bump: patch
plugins:
  - sidequest
---

Three Sidequest MCP tool friction points, found filing tickets on a real
board:

- `add` now accepts `dependsOn: string[]`. Each ref becomes a depends-on
  link to the new ticket in the same call, so a dependent ticket no longer
  needs a follow-up `link` call.
- `storyId` (on `add` and `update`) now accepts either the `US-n` story ref
  or the internal story id (`st_...`) that `story` returns, instead of
  refusing the id form.
- `update --files` (and `add --file`) no longer warns that a declared glob
  scope "does not exist in the repo" — a glob is a valid scope for files an
  executor will create, and the old check couldn't tell that apart from a
  typo. A plain (non-glob) path that doesn't exist is still flagged.
