---
ref: SQ-176
title: A merge from a published branch no longer demands that branch's tests from the negative-control gate
bump: patch
plugins:
  - sidequest
---

The negative-control gate now counts a commit as foreign when a remote-tracking ref that does not contain HEAD reaches it, as well as when a ref of the ticket's integration target does. Upstream develop merged into a fork PR branch is reachable from `refs/remotes/upstream/develop` but not from the PR branch, so its tests were still demanded. A branch that exists only in the local checkout, and a test that only the merge's conflict resolution changed, still need their `[sidequest:negative-control-test]` line.
