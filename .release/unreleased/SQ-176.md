---
ref: SQ-176
title: A merge from a remote's copy of the integration branch no longer demands that branch's tests from the negative-control gate
bump: patch
plugins:
  - sidequest
---

The negative-control gate now counts a commit as foreign when the integration branch, or a remote's copy of it, reaches it. Upstream develop merged into a fork PR branch is reachable from `refs/remotes/upstream/develop` but not from the PR branch, so its tests were still demanded. The remote's copy is `refs/remotes/<remote>/<the board's integration branch>`, and only a ref that does not contain HEAD counts. A branch that is only local, a feature branch that was merely pushed, and a test that only the merge's conflict resolution changed still need their `[sidequest:negative-control-test]` line.
