---
ref: SQ-109
title: An (anonymous) lizard row no longer hides a dropped named function that has a callback on its first line
bump: patch
plugins:
  - quartermaster
---

The CRAP gate treats an `(anonymous)` lizard row as standing in for a definition only when that
definition's own parameter list holds an arrow type. A callback that starts on the same line no
longer hides a named function lizard dropped.
