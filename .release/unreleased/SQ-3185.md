The three nudges now tell Claude to act instead of offering. The inline-work nudge says to file the ticket with `add` and dispatch now, and only a one- or two-file edit at a known location stays inline; it used to say "offer dispatch", which contradicted SessionStart. It counts PowerShell like Bash, no longer counts test and build runs (`npm test`, `node --test`, `node -e`, `npm run build`, `tsc`) as edits, and a board call quiets it only until the next user prompt instead of for the whole session. The Explore fan-out cap still stays lifted for the session after one board call. The prompt reminder dropped its "use informed inline judgment" ending and now fires on the first prompt that looks like a work request rather than on prompt one, so a greeting no longer uses it up. In a git repository root with no board, that prompt gets one line saying the first `add` creates the board and dispatch works through the default profile; temp folders, the Sidequest home, `~/.claude` and non-git folders stay silent, using the same rule board creation uses. SessionStart puts the standing-authorization sentence first in the orchestrator block. The `sidequest` skill description now leads with "default for multi-file or multi-step work, even where there is no board yet", and the inline carve-out moved to the skill body.
