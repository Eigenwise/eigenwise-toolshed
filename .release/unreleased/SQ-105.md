Board-only fragment for the #358 rework; the GH-315 and GH-357 fragments carry the release notes.

A file lizard gave no row now counts as measured only when every definition in it lies inside a row
read from its source, so one scanned method can no longer stand in for a function the scan could not
read. The source scan reads a regex whose character class holds a slash (`/[\\/]+/`) as one literal,
and a dropped function on the same line as another function's row gets a row of its own.
