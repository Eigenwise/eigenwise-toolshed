---
ref: SQ-3182
title: Ship Sonnet 5.5 as the gateway's Sonnet pin and rewrite every registered project at SessionStart
plugins:
  model-gateway: minor
  observability: patch
---

Model Gateway's shipped Sonnet fallback is now `claude-sonnet-5-5[1m]`, and `claude-sonnet-5[1m]` counts as a value it wrote, so it gets replaced. Every pin refresh (SessionStart, `setup`, `env --write-project`) now checks all registered wired projects and rewrites gateway-owned pins that disagree with the effective pin. Before this it only did that when the refresh itself moved a pin, so a new shipped default never left the project you opened. Observability prices `claude-sonnet-5-5` at the Sonnet 5 rate.
