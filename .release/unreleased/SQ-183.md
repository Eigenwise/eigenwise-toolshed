---
ref: SQ-183
title: A detached worktree no longer proves a non-reachable working-tree delivery
plugins:
  sidequest: patch
---

`groomClose` with `deliveryMethod` and a candidate the target branch does not contain now accepts the working-tree content proof only when the target branch itself is checked out. A detached checkout at the target tip is refused with `working_tree_requires_target_branch`, because its uncommitted bytes are not on the branch. Check out the target branch, or commit the content and deliver a target-reachable commit (or name a `deliveryRevision`). Reachable-commit and `deliveryRevision` deliveries from a detached worktree are unchanged.
