plugins:

`rework` only ever accepted the submitter's own `by` identity, but the CLI help, the parked-submission refusal guidance, and the release-path pending_submission message all told you to pass `--by <reviewer>`, so following the documented form always failed. They now say `--by <submitter id>` and point at `sidequest pulse`'s `submittedBy` field. The `rework` not_owner refusal also said "<ref> has no claim to release", copied from the unrelated release path even though nothing was being released; it now says `rework requires by = the submitter "<id>" (pulse -> submittedBy); got "<by>".` The generic release wording is unchanged for actual release refusals.
