---
ref: SQ-3204
title: "test:files now typechecks before running, so a tsc error in a named test file fails the pinned verify instead of only test:full and the release cut"
bump: patch
plugins:
  - sidequest
---

`npm run test:files` ran the TS loader (`tsx`) over the named test files without ever invoking `tsc`, so a type error in a test file a ticket's pinned verify named still passed. Only `npm run test:full` (and the release cut, which runs it) caught the error, costing a full cut re-run. `test:files` now runs `npm run typecheck` first (a whole-plugin `tsc -p tsconfig.json --noEmit`, under a second with the installed TypeScript 7 native compiler), so a delivered candidate can no longer carry a tsc error in a file its verify named.
