---
ref: SQ-124
title: Pin git identity for the sync-check mid-merge fixture so it conflicts on a CI runner
bump: patch
plugins: [sidequest]
---
The sync-check mid-merge test ran `git merge` without an identity. On a runner that cannot resolve one, git exits 128 before conflicting, leaving no unmerged entries. The fixture now pins the identity and asserts the merge stopped on a conflict.
