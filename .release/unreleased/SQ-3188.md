title: "Executor closeout guidance never names its own launch, and a reduced Agent-schema dispatch carries no launch name to a TaskStop instruction (GH-339)"
bump: patch
plugins:
  - sidequest
---

The executor persona's terminal-closeout guidance already scoped `TaskStop` to tasks the executor itself spawned, but left that implicit. It now says so explicitly: `TaskStop` never targets the executor's own launch, whether or not the host reports a name for it, and retiring a finished executor's own launch stays the orchestrator's job. A regression test locks in that a reduced Agent-schema dispatch's briefing (and a normal dispatch's briefing) never mentions `TaskStop` alongside a launch name.
