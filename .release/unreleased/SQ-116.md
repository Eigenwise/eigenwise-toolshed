---
ref: SQ-116
title: Read a negative-control marker's command from after its assertion
bump: patch
plugins:
  - sidequest
---

The completion gate now takes a negative-control marker's failed count from the command that follows the assertion, so a `failed=<n>` quoted inside the assertion prose no longer overrides the real count, and a marker with no command before `failed=<n>` is refused again.
