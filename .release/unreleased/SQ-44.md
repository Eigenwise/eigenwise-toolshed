---
ref: SQ-44
title: CRAP gate reads its config from the measured root and refuses stale coverage
bump: patch
plugins: [quartermaster]
---

The CRAP gate measures the git checkout it runs in, reads `crap.json` from there unless `--project`
names another config, gives each run its own `QUARTERMASTER_COVERAGE_DIR`, and exits 2 when a coverage
command exits 0 without writing fresh coverage.
