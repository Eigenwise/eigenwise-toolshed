title: "The CRAP gate no longer scores a function twice when lizard names it (anonymous)"
bump: patch
plugins: [quartermaster]
---

lizard names a function with an arrow-typed parameter (`function retry<T>(work: () => T, t = 5)`) "(anonymous)". The source scan added for GH-357 read that definition again and reported it a second time as `retry source=source-scan`. A lizard row called "(anonymous)" that starts on a definition's line now stands for that definition, so the gate reports it once.
