title: Keep the board answering while integrate runs its merged-tree gate
bump: minor
plugins:
  - sidequest
---

MCP `integrate` used to run the whole merged-tree gate synchronously inside the board server, so pulse, comment and dispatch on every board waited behind it and Claude Code aborted the call after 30 minutes of silence. The server now delivers in a detached child process with its own mutation queue, sends MCP progress notifications per gate phase and file and at least every 30 s, and the delivery records its own state. `pulse <ref>` shows an `integration` block (running, delivered, rolled_back, rollback_failed or refused, phase, current gate file, log path), which survives a client that gave up or a server that was killed mid-gate.
