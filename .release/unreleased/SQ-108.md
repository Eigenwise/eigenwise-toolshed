The at-risk status read canonicalizes the path a quarantined tree was renamed from once per call and hands that value down, and the rebase of a link target from that path onto the moved tree is its own small helper, so the per-component and per-entry checks are back under the complexity bar. The orchestration reference now lists the `dependency_link_changed` sweep detail (`<path> is no longer the dependency link that was recorded`) beside the other dependency-link parks.
