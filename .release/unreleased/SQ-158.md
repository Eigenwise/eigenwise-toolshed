---
ref: SQ-158
title: removeFiles keeps a written non-ASCII file in scope
bump: patch
plugins:
  - sidequest
---

`update removeFiles` on a live claim lists what the bound checkout has written so it can refuse to revoke it. That list was read with git's default C-quoting, so a non-ASCII name such as `café.ts` came back as an escaped string no declared path matched, and the removal succeeded. Both git calls now use `-z` and the output is split on NUL. `cmdScopeRequest` also hands its ruling output to named helpers.
