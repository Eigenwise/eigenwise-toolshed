---
ref: SQ-3881
title: Stop worktree provisioning from emptying the main checkout's node_modules
bump: patch
plugins:
  - sidequest
---

Worktree provisioning no longer links a scoped plugin's node_modules to the registered checkout. Worktree setup ran `npm ci` through that link, which emptied the main checkout's install on every sidequest-scoped dispatch, and quality-gate's realpath tests saw a path outside the plugin root. A scoped plugin now gets a real install from setup, or an install deferred to the executor's first step. Integration checkouts unlink configured dependency links before `git worktree remove`, which on Windows deletes through a junction.
