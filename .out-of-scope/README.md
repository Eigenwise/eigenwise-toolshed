# Out of scope

Each file here is one standing refusal, dated, with the evidence behind it.

1. Before arguing for a mechanism listed here, read its note. The evidence is why it was refused.
2. A new refusal gets a short file: what was asked, the evidence with numbers, the decision, and what would change it.
3. Reopen a note only with a new observed failure in v2 that the note did not cover. Opinions and imagined failures do not count.
4. `SCOPE.md` is the admission bar. This folder is what failed it.
5. Notes cite public issue numbers only.
