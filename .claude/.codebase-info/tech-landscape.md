# Tech landscape

Last Updated: 2026-09-10

- Node.js is the common runtime. Sidequest uses TypeScript, esbuild, SQLite, and Node's test runner; its build is in `plugins/sidequest/scripts/build.mjs`, generates Markdown agents in `plugins/sidequest/agents/` through `scripts/generate-bundled-agents.mjs`, and release suite resolution is shared with `scripts/release/lib/suites.mjs` through `plugins/sidequest/lib/suite-resolver.js`.
- The Sidequest dashboard uses Svelte 5, TypeScript, Vite 7, Tailwind's Vite plugin, Vitest, and Playwright. Source is `plugins/sidequest/dashboard/app`; production output is `plugins/sidequest/dashboard/dist`.
- Quartermaster, Observability, Model Gateway, live-rules, and codebase-mapper ship JavaScript hooks and skills. Hook registrations are in each `hooks/hooks.json`; Codebase-mapper uses declarative `PreToolUse: Skill` and `Stop` hooks. Model Gateway also maintains local updater/serving-version state, supports ephemeral shim ports, and supervises cache-sibling replacement and shutdown; startup, recovery, restart, and drain use bounded owner probes, leaving unknown or foreign listeners untouched, with POSIX `ps -ww` preserving full commands. Observability's Grafana sink applies per-request Astra pricing and reports unpriced usage as tokens.
- Whittle uses Node.js lifecycle hooks, JavaScript OpenCode/Pi adapters, and a Python Hermes adapter. Its parameterless MCP prompt/tool uses pinned `@modelcontextprotocol/sdk` 1.26.0 and `zod` 3.23.0; its root package lock and `npm test` are discovered through the existing release suite resolver. The canonical policy is exported as static host instructions. There is no mode preference storage or statusline.
- Model Gateway adds dev-only Ajv 8.20.0 for Draft 2020 schema compatibility regression checks. Its package script preserves complete test-file discovery, caps file concurrency at two to limit shared process-probe contention, and uses `npm ci` for cold setup. Production adaptation is local JavaScript.
- The docs site uses Astro 7 and Starlight. Configuration is `docs/astro.config.mjs`; reference pages are generated by `docs/scripts/generate-reference.mjs`.
- The Windows Sandbox harness is PowerShell under `sandbox/windows/` (gitignored, maintainer-only, no public docs page); its contract test is `sandbox/windows/Test-ToolshedSandbox.ps1`.
- CI uses GitHub Actions. `.github/workflows/test.yml` runs release and plugin suites; release guard and release cut are separate workflows.
- There is no repository database service or Docker setup. Sidequest's local SQLite store is runtime state, not infrastructure.
