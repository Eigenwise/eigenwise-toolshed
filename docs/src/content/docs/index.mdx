## What it is

The Toolshed is a set of plugins for Claude Code. A plugin adds skills, tools and screens to Claude Code. This release is called Toolshed 2.

You describe what you want. The plugins plan the work, keep track of it on a board (a list of the work), send each piece to a model that fits it, and show you what happened. When bigger work is done, it is pushed as a branch and opened as a pull request for you. In a repository other people commit to, the merge stays yours.

Everything they keep is a plain file in your project. You can open it, edit it and delete it.

## Why it exists

Claude Code does good work in one sitting. Over weeks, three things go wrong.

- **Work gets lost.** A long task lives in one chat. When the chat ends, so does the plan.
- **Every task costs the same.** A one-line lookup runs on the same model as a hard design change.
- **The setup never improves.** You type the same command for the fortieth time and nothing notices.

The Toolshed fixes those three, and it never changes your setup without asking.

## The five plugins

Each one works alone. Install one, or all five.
