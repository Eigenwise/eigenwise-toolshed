# Quality Gate

Quality Gate owns the JavaScript and TypeScript AST complexity, stable function identities, V8 coverage matching and per-function CRAP calculation used by the Toolshed repository gate. Each changed function carries a `classification`: `new` (no partner at the base), `modified-raised` (its complexity rose since the base) or `legacy-unchanged` (its complexity held or fell). Only new complexity the change introduced is enforced: a `new` or `modified-raised` function at 6 fails and one without coverage stays unverified, while a `legacy-unchanged` function is reported with its number and never fails, so a pass-through edit inside a legacy body is not a refactor demand. The parser uses TypeScript 7 from the scored project first, then the plugin’s own dependency (install it with `npm install` in this directory); if neither has the supported parser API, measurement refuses with both locations named. Run `node bin/quality-gate.js measure --project <root> --base <revision> --coverage <V8-directory> <files...>` to print the measurement report as JSON. This entry consumes existing coverage and does not run tests, configure a project or install hooks. The repository gate keeps its existing CLI and report format.
