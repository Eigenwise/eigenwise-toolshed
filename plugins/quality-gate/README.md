# Quality Gate

Quality Gate owns the JavaScript and TypeScript AST complexity, stable function identities, V8 coverage matching and per-function CRAP calculation used by the Toolshed repository gate. A score of 6 fails; missing coverage stays unverified. The parser uses TypeScript 7 from the scored project first, then the plugin’s own dependency (install it with `npm install` in this directory); if neither has the supported parser API, measurement refuses with both locations named. Run `node bin/quality-gate.js measure --project <root> --base <revision> --coverage <V8-directory> <files...>` to print the measurement report as JSON. This entry consumes existing coverage and does not run tests, configure a project or install hooks. The repository gate keeps its existing CLI and report format.
